# Golden Cases 框架

此目录预留给可追溯的真实 golden cases。当前不包含任何历史正确答案、输入样本或可执行断言。

未来新增 case 时，每个 case 应同时记录：

- 真实且可定位的数据来源、数据版本与取得时间；
- 输入（板块、股票、日期、配置和完整所需上下文）；
- 经业务确认的预期输出及确认依据；
- 覆盖范围（状态机、T/T-1、排名、评分等）；
- 对应的回归测试入口。

不得从当前代码输出反推并固化为“正确答案”，也不得用 golden case 覆盖或掩盖未解释的行为变化。

目录分类：

- `lifecycle/`：板块生命周期状态机。
- `date_alignment/`：交易日、T/T-1 与时间窗口。
- `ranking_scoring/`：龙头、多股票 PK、多日评分、市场排名、权重与归一化。
- `data_integrity/`：future data leakage、缺失数据与输入完整性。
